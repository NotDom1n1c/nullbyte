[ 03 ]// how bits become things

Text

Each character maps to a number via ASCII / UTF-8. A = 65 = 01000001. UTF-8 extends this to every language using 1–4 bytes. Type a character:

Images

A pixel is three bytes — R, G, B — each 0–255. Mixed, they make any of 16.7M colors. Drag to mix one pixel:

Sound

Audio is a wave measured thousands of times a second. Sample depth = how many bits per measurement: 8-bit = 256 loudness steps (gritty), 16-bit = 65,536 steps (CD quality), 24-bit = studio. More bits = finer the staircase that approximates the smooth wave.

Numbers

Plain unsigned bytes count 0–255. Signed bytes use two's-complement so the top bit means negative (−128…127). Floating point splits bits into sign, exponent and mantissa.

[ 04 ]// flags, masks & endianness

Bit flags & bitmasks

One byte can pack 8 yes/no switches. Unix file permissions do exactly this — click a permission to toggle its bit and watch the octal value (like chmod 755) change.

chmod value: 000

Endianness

When a value spans several bytes, which byte comes first? Big-endian stores the most-significant byte first (like we write numbers); little-endian (x86) stores the least-significant first. The number 0x12345678 in memory:

Big-endian:    12 34 56 78
Little-endian: 78 56 34 12

Mixing them up is a classic bug when parsing network packets or binary files. See raw bytes in the crypto tools.
