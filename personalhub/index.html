Personal Hub needs a local server

You opened this page directly from disk (file://). Browsers block ES-module scripts on file:// for security, so this app can't start — that's the blank/white screen you're seeing.

Run a tiny server from the nullbyte folder, then reopen the site from localhost:

npx --yes http-server -p 8099 -c-1

…or just double-click start-server.cmd in the nullbyte folder.
