Why the dictionary worked

An unsalted hash is deterministic: md5("password") is always the same string. Attackers precompute hashes for millions of common passwords (a rainbow table) and just look yours up — billions of guesses per second on a GPU. Any password in the list falls instantly.

How salting stops it

A salt is random data added before hashing, unique per user. Now the same password hashes differently for everyone, so precomputed tables are useless — each guess must be recomputed per salt.
