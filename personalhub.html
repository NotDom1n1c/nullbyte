Personal Hub needs a local server

You've opened this site directly from disk (file://). Browsers block ES-module scripts on file://, so Personal Hub can't start — the other tools on this site work fine, but this one is a bundled app and needs to be served over HTTP.

Double-click start-server.cmd in the nullbyte folder, or run this from that folder:

npx --yes http-server -p 8099 -c-1

Then open http://localhost:8099/personalhub.html.
