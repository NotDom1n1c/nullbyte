Why byte-level?

Two files can look identical yet differ by a single flipped bit — a patched jump instruction, a changed config flag, a swapped C2 domain. A text diff misses binary changes entirely. Comparing raw bytes and rendering them as hex shows exactly what changed and where, down to the offset.

Reading the view

Each row is 16 bytes. The offset column is the hex address into the file. Bytes that differ between A and B are boxed in red; bytes that exist in only one file (because the files are different lengths) are amber. Pair this with the File Inspector for magic bytes & entropy.
